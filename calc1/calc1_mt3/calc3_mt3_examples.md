## Functions of Single Variables (Review)

* Find the domain of $f(x) = \sqrt{x-2}$.

  **Solution:**  Since the square root function is only defined when its input is greater than or equal to 0, we need to find the values of $x$ such that $x-2 \geq 0$.  Rewriting this inequality gives $x \geq 2$. The domain is $[2, \infty)$.

## Limits

The main thing to remember about limits is that we are analyzing the behavior of a function as we approach a particular point.  The limit exists if and only if the left-hand and right-hand limits exist and are equal.

* Evaluate $\lim_{x \to 2} (x^2 - 1)$.

   **Solution:** We can directly substitute $x = 2$ into the function to get $2^2 - 1 = 3$.

## Derivatives

The important things to remember here are that the derivative measures the instantaneous rate of change of a function, and we compute it using limits and the definition of the derivative.

* Let $f(x) = x^2$.  Find $f'(x)$.

   **Solution:** Using the power rule, $f'(x) = 2x$.

* Let $f(x) = x^3 + 2x$.  Find $f'(x)$.

   **Solution:** $f'(x) = 3x^2 + 2$.

   Here, we used the power rule and the sum rule.
