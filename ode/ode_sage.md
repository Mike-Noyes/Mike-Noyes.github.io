# Sage Resources

We will be using Sage extensively.  Sage is a freely available web-based mathematical software that is extremely powerful and fairly easy to use.  It is very similar to Python, so if you have a little bit of Python programming experience, you should be able to pick it up pretty quickly.  If you don't have any Python experience, **NO PROBLEM!**  You'll be able to look at the code and figure things out in no time.

Each week there will be shared Sage cells that we will use to help visualize and solve differential equations.  You will find the links to these cells in the *Sage Links* pages.  

I've included here some links to websites that will help you learn Sage and to some files that will be useful.  Please take a look and happy Sage-ing!

## Links

The main Sage cell page.  This only gives you one active cell, but for simple problems this is all that you’ll need.

* [Sagecell](https://sagecell.sagemath.org/)

A page of Sage cells.  The nice thing about this is functions and matrices and various other things defined in one cell are callable in all other cells.  This can be very useful, especially if you’re working through a multi-step problem. 

* [Multiple Sagecells](https://understandinglinearalgebra.org/sage/sage.html)

Here are some Sage tutorials.  The first one is mainly a bunch of examples about specific topics and includes tons of sample calculations.  I have linked it directly to the main topic page for Differential Equations.  If you want to see some of the other topics available, click on the topics tab at the top of the page.  The second is a very good general overview of Sage, though there isn’t anything that’s directly about Differential Equations.

* [Sage Cell Repository](http://sage-cell-repository.wikidot.com/diff-equations)
* [SDSU Sage Tutorial](https://mosullivan.sdsu.edu/sagetutorial/index.html)

Here’s a page with some interesting interactive Sage cells.  Not all of these are active cells, but you can learn a lot by looking through them.

* [Sagemath Wiki](https://wiki.sagemath.org/interact/diffeq)
