## Functions of Single Variables

* Find the domain of $f(x) = \frac{1}{x-3}$.

  <details>
  <summary><strong>Solution</strong></summary>

  The denominator cannot be zero, so we need $x - 3 \neq 0$, which means $x \neq 3$.

  The domain is all real numbers except 3, or $(-\infty, 3) \cup (3, \infty)$.

  </details>

* Find the range of $f(x) = x^2 + 1$.

  <details>
  <summary><strong>Solution</strong></summary>

  Since $x^2 \geq 0$ for all real $x$, we have $f(x) = x^2 + 1 \geq 1$.

  The minimum value is 1 (achieved at $x = 0$), and there is no maximum.

  The range is $[1, \infty)$.

  </details>

## Limits

* Evaluate $\lim_{x \to 3} (2x + 1)$.

  <details>
  <summary><strong>Solution</strong></summary>

  Since this is a polynomial, we can directly substitute:

  $$\lim_{x \to 3} (2x + 1) = 2(3) + 1 = 7$$

  </details>

## Derivatives

* Find $f'(x)$ for $f(x) = 5x^2$.

  <details>
  <summary><strong>Solution</strong></summary>

  Using the power rule: $f'(x) = 5 \cdot 2x = 10x$

  </details>

* Find $f'(x)$ for $f(x) = \sin(x)$.

  <details>
  <summary><strong>Solution</strong></summary>

  The derivative of sine is cosine:

  $$f'(x) = \cos(x)$$

  </details>
