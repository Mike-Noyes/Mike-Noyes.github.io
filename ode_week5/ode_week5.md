## Quick Introduction

This final week covers *Laplace Transforms and Applications*.  The Laplace transform is a powerful tool for solving differential equations, especially those with discontinuous forcing functions or complex initial conditions.  This transform converts differential equations into algebraic equations.

The most important topics are *Laplace transforms*, *inverse transforms*, *solving IVPs with Laplace transforms*, and *transfer functions*.  Please note that the Laplace transform is particularly useful for systems with piecewise-defined inputs.

After learning the Laplace transform method, we see how it connects to frequency domain analysis and system response.  These ideas extend naturally to engineering applications.

Given any initial value problem, we can use the *Laplace transform* to find solutions efficiently.  **PLEASE NOTE** that this method is especially powerful for problems with complicated driving forces.
